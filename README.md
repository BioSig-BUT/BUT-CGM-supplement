# DistriMuSe Database Visualization

A Python application for visualizing data from the DistriMuSe database.  
The application enables the visualization of long-term biological and behavioral records.

Supported data:

- continuous glucose monitoring (CGM),
- heart rate,
- calorie intake,
- physical activity,
- step count,
- sleep,
- accelerometer data.

### Application Features

- Interactive record visualization
- Zooming and panning through data
- Displaying multiple data types simultaneously
- Filtering by time range
- Statistics and summaries of selected data

### Requirements

- Python 3.12
- Windows operating system

---

## Running the Application

Enter all following commands into the terminal:
- PowerShell or CMD

Open the terminal in the project root directory (the folder containing the `main.py` and `requirements.txt` files).

### Creating a Virtual Environment

```bash
python -m venv venv
```
### Activating the Virtual Enviroment
```bash
venv\Scripts\activate 
```
After activation, the terminal should display the `(venv)` prefix.

### Installing Dependencies
```bash
pip install -r requirements.txt
```

### Starting the Application
```bash
python main.py
```
